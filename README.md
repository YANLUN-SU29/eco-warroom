# 風機與牠們的產地｜海陸空生態戰情室

115 年度大專院校能源開放資料創意競賽「用 AI．懂能源」　團隊：三鳥牌

用政府開放資料拆解離岸風電的三個都市傳說：鳥類果汁機（天空）、海豚殺手（水下）、
低頻噪音（陸地）。網站是一頁式靜態頁，掛在 GitHub Pages。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站，樣式與互動都內嵌在裡面 |
| `data.json` | 由抓取器產生，前端只讀這一支 |
| `scripts/fetch_data.py` | 向政府開放資料出處抓取、清洗、計算 |
| `.github/workflows/update-data.yml` | 每半小時自動重跑抓取器並 commit |

## 資料怎麼來的

政府站台多半沒有開放 CORS，瀏覽器沒辦法直接連。所以抓取放在後端（GitHub Actions
排程，或在自己電腦上跑），結果寫進 `data.json`，前端只讀同網域的檔案。

手動更新一次：

```bash
py -3 scripts/fetch_data.py
```

只用 Python 標準函式庫，不需要 `pip install`。

### 介接的四個出處

| 面向 | 出處 | 取到的數字 |
|---|---|---|
| 發電（即時） | 台電《即時各機組發電量》JSON | 離岸風場總出力 MW、風場數、各風場出力 |
| 發電（年） | 經濟部能源署《發電量年資料》CSV（[data.gov.tw/16481](https://data.gov.tw/dataset/16481)） | 全國風力年發電量、逐年成長率（自行重算） |
| 水下 | 海保署《iOcean 海洋生物目擊回報》CSV（[data.gov.tw/157621](https://data.gov.tw/dataset/157621)） | 近 12 個月鯨豚／中華白海豚目擊筆數、最近一筆日期 |
| 天空 | 農業部 TBN 物種觀測 API v2.6 | 風場所在縣市近 12 個月鳥類觀測筆數；另每日翻完分頁統計物種數、保育類數與代表物種 |

陸地的低頻噪音沒有即時 API。畫面上的 `0.0 dB(A)` 來自環境部《海洋竹南離岸式風力發電
計畫（第 6 次變更）》的 SoundPLAN 模型，在 `data.json` 裡標成 `status: "model"`，
UI 也註明「非即時感測」。

水下的海底剖面互動（白海豚水深 <10 m、風場水深 >20 m、人工魚礁效應）同樣是示意圖，
依國家海洋研究院《離岸風電場生態保育環境監測研究－苗栗及雲彰風場期末報告》繪製，
圖下方另以 iOcean 的實際目擊筆數對照，兩者在畫面上分開標示。

人工魚礁效應的數字沒有沿用提案書的「漁獲量兩倍」——查證後找不到能支撐的原始文獻。
改用 Bicknell 等（2026）Frontiers in Marine Science 13:1765872 的實測值：蘇格蘭
Beatrice 風場管架基座周邊 30 公尺處底棲魚類生物量約為 240 公尺處的 1.5 倍。
同一篇也指出無法判定是「吸引」還是「增產」，頁面上一併寫出來。

### 抓不到的時候

三個原則：

1. 每個來源各自獨立，一個掛掉不會拖垮其他來源。
2. 抓不到就標 `status: "unavailable"`，畫面顯示「來源無回應」，不編造數字。
3. 上一次成功的值會保留並標成 `stale`，讓人看得出資料停在哪一天。

頂端狀態燈會顯示「政府 API 已介接 n/4」，沒有全部到齊時會轉成琥珀色。

> TBN 已改版到 v2.6，舊的 `v25` 端點整個回 404（連官方文件自己列的範例網址也是）。
> 現行版本以 <https://www.tbn.org.tw/data/api> 這頁指到的為準，回傳的總筆數在
> `meta.total`（v2.5 以前是頂層 `count`），抓取器兩種都接。

物種統計要翻約 55 頁分頁，所以不是每次都算：`data.json` 裡記了 `sky.species_at`，
超過 24 小時才重算，其餘時間沿用舊值（物種組成本來就變得很慢）。物種數只算單一
物種，「鳥綱」「柳鶯屬」「小濱鷸; 紅胸濱鷸」「大冠鷲(hoya亞種)」這類條目會排除，
不然會灌水。

## 本機預覽

`index.html` 會 `fetch('./data.json')`，直接用 `file://` 開會被瀏覽器擋掉，
請起一個本機伺服器：

```bash
py -3 -m http.server 8765
```

然後開 http://127.0.0.1:8765 。
